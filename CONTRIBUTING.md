# Contribuindo

1. Crie uma branch para cada tarefa.
2. Faça alterações relacionadas somente àquela tarefa.
3. Use mensagens de commit curtas e descritivas.
4. Abra um Pull Request para a branch `main`.
5. Descreva o que foi alterado e como foi verificado.
6. Sempre que possível, solicite revisão de outro integrante antes do merge.

## Padrão de branches

- `feature/nome-da-tarefa`
- `fix/nome-do-problema`
- `docs/nome-da-documentacao`
- `chore/nome-da-manutencao`

Não versione arquivos compilados, pastas de build, segredos, tokens ou configurações pessoais da IDE.
