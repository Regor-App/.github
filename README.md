# Regor-App

Repositório de configuração e apresentação da organização **Regor-App** no GitHub.

O código dos trabalhos acadêmicos fica nos repositórios próprios. Este repositório centraliza a apresentação pública, orientações de contribuição e materiais de organização da equipe.

## Repositórios

| Repositório | Finalidade |
| --- | --- |
| [01-sistema-login](https://github.com/Regor-App/01-sistema-login) | Módulo de login em JavaFX, com autenticação didática `root` / `toor`. |
| [02-agenda-contatos](https://github.com/Regor-App/02-agenda-contatos) | Agenda de contatos em Java e Swing. |
| [03-projeto-livre](https://github.com/Regor-App/03-projeto-livre) | Projeto Livre Regor, ainda em desenvolvimento. |

## Organização

- [`profile/README.md`](profile/README.md): apresentação pública da organização.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): regras para branches, commits e Pull Requests.
- [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md): checklist padrão de Pull Request.
- `.github/ISSUE_TEMPLATE/`: modelos para registrar tarefas e problemas.

As demais pastas existentes neste repositório servem como materiais de referência e organização. A implementação oficial deve permanecer nos repositórios correspondentes de cada entrega.

## Regra de colaboração

A `main` deve receber alterações por Pull Request. Cada tarefa deve usar uma branch descritiva e o PR deve explicar claramente o que foi alterado.
