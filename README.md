# Estrutura do Regor

Este é o repositório `.github` da organização **Regor-App**. Ele contém o [perfil público da organização](profile/README.md) e a estrutura inicial de pastas descrita para o projeto acadêmico Regor, desenvolvido para a disciplina de Programação Orientada a Objetos.

Cada pasta e subpasta possui um `README.md` explicando sua finalidade, os arquivos que deve receber e como organizá-los.

## Pastas

| Pasta | Finalidade |
| --- | --- |
| [`profile/`](profile/README.md) | Apresentação exibida na página pública da organização no GitHub. |
| [`src/`](src/README.md) | Código-fonte Java da aplicação. |
| [`resources/`](resources/README.md) | Telas FXML, estilos, ícones e imagens. |
| [`database/`](database/README.md) | Modelagem e scripts de banco de dados. |
| [`docs/`](docs/README.md) | Documentação técnica, UML, protótipos e apresentações. |
| [`support/`](support/README.md) | Documentos, vídeos, tutoriais e referências de apoio. |

## Como usar

1. Abra o README da pasta correspondente ao material que deseja adicionar.
2. Coloque cada arquivo na pasta indicada, com um nome que explique seu conteúdo.
3. Atualize o README quando a finalidade ou a organização da pasta mudar.
4. Preserve os arquivos editáveis dos diagramas e apresentações junto das exportações, quando possível.

## Situação atual

A estrutura foi criada para receber o projeto. As pastas de código, recursos, banco de dados e documentação ainda contêm apenas seus READMEs. Não há código executável, banco configurado ou materiais de implementação nestas pastas.

As funcionalidades e tecnologias apresentadas no perfil da organização descrevem a proposta do Regor; a implementação deverá ser documentada à medida que for adicionada.
