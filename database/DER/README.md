# Diagrama Entidade-Relacionamento

Pasta destinada ao DER, que apresenta as entidades do domínio, seus atributos e os relacionamentos.

## O que colocar aqui

- Arquivo editável do diagrama.
- Exportações do DER em imagem ou PDF.
- Notas sobre cardinalidades e regras de relacionamento.

## Organização

Represente as entidades previstas para o Regor e indique suas cardinalidades. Atualize o DER quando houver mudanças relevantes na modelagem. Exemplo de nome: `regor-der.drawio`.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
