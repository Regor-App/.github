# Diagrama lógico

Pasta destinada ao diagrama lógico do banco de dados, que transforma a modelagem conceitual em tabelas e relacionamentos.

## O que colocar aqui

- Tabelas e suas colunas.
- Chaves primárias e estrangeiras.
- Tipos de dados, restrições e tabelas associativas.

## Organização

Mantenha o modelo lógico consistente com o DER e com os scripts SQL. Guarde o arquivo editável junto de uma exportação para consulta. Exemplo de nome: `regor-modelo-logico.pdf`.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
