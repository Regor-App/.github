# Banco de dados

Pasta destinada à modelagem dos dados e aos scripts de banco de dados do Regor.

## O que colocar aqui

- Modelos que representam usuários, interesses, publicações, curtidas e combinações.
- Definição de tabelas, relacionamentos e restrições.
- Scripts de criação e dados fictícios para desenvolvimento.

## Subpastas

| Pasta | Finalidade |
| --- | --- |
| [`DER/`](DER/README.md) | Diagrama Entidade-Relacionamento. |
| [`DL/`](DL/README.md) | Diagrama lógico do banco de dados. |
| [`scripts/`](scripts/README.md) | Scripts SQL. |

## Organização

Mantenha os modelos e scripts coerentes entre si. O sistema gerenciador de banco de dados e sua integração com a aplicação ainda devem ser definidos.
