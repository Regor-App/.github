# Scripts de banco de dados

Pasta destinada aos scripts SQL usados para criar e preparar o banco de dados.

## O que colocar aqui

- Criação de tabelas e relacionamentos.
- Alterações de estrutura, índices e restrições.
- Dados fictícios e consultas de apoio aos testes.

## Organização

Indique o banco compatível e a ordem de execução em cada script. Use nomes ordenados, como `001-criar-tabelas.sql` e `002-dados-exemplo.sql`. Documente operações que apaguem dados.

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
