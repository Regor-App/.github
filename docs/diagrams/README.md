# Diagramas gerais

Pasta destinada aos diagramas de arquitetura e aos fluxos gerais do sistema.

## O que colocar aqui

- Visão das camadas da aplicação.
- Fluxos de autenticação, publicação e combinação de interesses.
- Diagramas de comunicação entre interface, serviços e persistência.

## Organização

Use esta pasta para diagramas gerais. Coloque UML em `docs/uml` e modelos de banco em `database/DER` ou `database/DL` para facilitar a localização.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
