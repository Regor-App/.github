# Apresentações

Pasta destinada às apresentações produzidas para explicar e demonstrar o Regor.

## O que colocar aqui

- Slides para aulas, avaliações e demonstrações.
- Apresentações sobre os conceitos de POO aplicados.
- Roteiros de apresentação e versões exportadas em PDF.

## Organização

Use nomes com tema e data, como `regor-apresentacao-2026-10-05.pptx`. Indique a versão demonstrada e diferencie recursos implementados de funcionalidades planejadas.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
