# Interface e experiência do usuário

Pasta destinada ao planejamento das telas e dos fluxos de navegação do Regor.

## O que colocar aqui

- Wireframes e protótipos de cadastro, login, perfil e feed.
- Fluxos de descoberta de pessoas e matching.
- Paleta de cores, tipografia e decisões de usabilidade.

## Organização

Identifique a tela e a versão de cada material. Registre decisões que ajudem a implementar uma navegação consistente e acessível em JavaFX.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
