# Diagramas UML

Pasta destinada aos diagramas UML que documentam a estrutura e o comportamento orientado a objetos do Regor.

## O que colocar aqui

- Diagrama de classes com atributos, métodos e relacionamentos.
- Diagramas de casos de uso.
- Diagramas de sequência e atividades.

## Organização

Use os nomes reais das classes quando elas forem implementadas. Revise os diagramas após alterações no código e preserve seus arquivos editáveis.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
