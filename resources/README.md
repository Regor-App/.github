# Recursos da aplicação

Pasta destinada aos arquivos que a aplicação utiliza além do código Java.

## O que colocar aqui

- Layouts de telas em FXML.
- Folhas de estilo CSS.
- Ícones e imagens utilizados na interface.

## Subpastas

| Pasta | Finalidade |
| --- | --- |
| [`icons/`](icons/README.md) | Ícones da interface. |
| [`images/`](images/README.md) | Imagens da aplicação. |

## Organização

Configure o carregamento destes recursos no projeto JavaFX quando a aplicação for adicionada. Prefira caminhos relativos ao classpath em vez de caminhos específicos de um computador.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
