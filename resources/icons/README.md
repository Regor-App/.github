# Ícones

Pasta destinada aos ícones da interface do Regor.

## O que colocar aqui

- Ícones de navegação, como início, perfil e configurações.
- Ícones de ações, como curtir, editar e sair.
- Variações de ícones para diferentes estados de um botão.

## Organização

Use nomes descritivos, como `perfil.png` e `curtir.png`, e mantenha um padrão visual. Verifique a compatibilidade do formato com o carregador utilizado na aplicação.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
