# Imagens

Pasta destinada às imagens estáticas utilizadas pelo Regor.

## O que colocar aqui

- Logotipo e elementos da identidade visual.
- Imagens de fundo e ilustrações das telas.
- Avatares padrão e imagens de demonstração sem dados pessoais.

## Organização

Use nomes descritivos e tamanhos adequados à interface. Fotos enviadas por usuários devem ter uma estratégia própria de armazenamento; esta pasta serve aos recursos estáticos do projeto.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
