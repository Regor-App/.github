# Materiais de apoio

Pasta destinada a materiais de estudo e consulta que apoiam o desenvolvimento do Regor.

## O que colocar aqui

- Documentos acadêmicos e orientações da disciplina.
- Vídeos e tutoriais úteis à equipe.
- Referências de tecnologias e conceitos utilizados.
