# Documentos de apoio

Pasta destinada a documentos externos ou acadêmicos utilizados como apoio ao projeto.

## O que colocar aqui

- Enunciados de trabalhos e critérios de avaliação.
- Guias de organização e materiais da disciplina.
- Anotações de estudo que auxiliem a equipe.

## Organização

Identifique o assunto e, quando aplicável, a fonte do documento. A documentação técnica produzida para o Regor deve ficar em `docs`.

## Situação atual

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
