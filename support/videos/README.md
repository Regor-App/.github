# Vídeos de apoio

Pasta destinada a referências de vídeo e demonstrações relacionadas ao projeto.

## O que colocar aqui

- Links para aulas e explicações sobre Java, JavaFX e POO.
- Gravações curtas de demonstração do Regor.
- Roteiros e descrições de vídeos usados pela equipe.

## Organização

Prefira registrar links em arquivos Markdown quando o vídeo for grande. Informe título, autor ou canal e o assunto abordado; para demonstrações, indique a versão do projeto.

Esta pasta está preparada para receber os arquivos do projeto. Neste momento, contém apenas documentação e, quando indicadas acima, subpastas também documentadas.
